# 🎮 Word Duel

A JavaScript typing game designed to improve typing speed and accuracy through a simple and interactive gameplay experience.

## ✨ Features

* ⌨️ Typing-based gameplay
* 🎯 Score tracking
* 🔄 Restart the game
* 🧠 JavaScript-based game logic

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/aminrasooli2007-svg/word-duel.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

## 🎮 How to Play

Start the game and type the displayed words as quickly and accurately as possible.

Try to improve your score and typing accuracy with each attempt.
